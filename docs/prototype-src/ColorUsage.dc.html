主信息卡一屏只放一个Primary Container 是最醒目的面，只给天气这种核心信息；其他卡片用 Surface Container 系列，按层级由浅到深。
提示栏按严重程度选色信息 → Tertiary，警告 → Warning，错误 / 病害 → Error，完成 → Primary Container。操作后的临时反馈统一用 Snackbar。
布局里不写死色值XML 只引用 ?attr/colorXxx，色值集中写在 values/ 与 values-night/ 的 colors.xml，深色模式和动态取色都能自动生效。
