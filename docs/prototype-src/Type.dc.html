中文排版规则 1. 字号单位一律 sp，跟随系统字体缩放；不要写死 TextView 高度。 2. 中文 letterSpacing 设为 0，M3 英文字距不要套到中文上。 3. 标题类（Title 及以上）中文用 Medium 500，否则显得发虚。 4. 最小 12sp；11sp 只给数字、角标和免责说明。 5. 长段落（百科、AI 回答）用 Body Large 16/24。
