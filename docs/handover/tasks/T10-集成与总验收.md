## 1. 模拟数据导入接线

- **文件**：`app/src/main/java/com/heban/app/data/mock/MockDataImporter.java`
- **现状**：
  - `importNow()` 只读取 `MockJson.PESTS`、`MockJson.PRODUCTS`；
  - `writeAll()` 只调用 `importPests` / `importProducts`；
  - `MOCK_VERSION = 1`；
  - `needsImport()` 只检查百科表和共享商品表是否为空。
- **要改**：
  1. 在同一个事务（`db.runInTransaction`）里，调用 `CommunityMockData.importInto(app, db, gson)`（T1）和 `MallMockData.importInto(app, db, gson)`（T2）。这两个方法会抛 IOException，需要先读文件再进事务；可以调整它们的签名，拆成「解析」和「写入」两步。
  2. `MOCK_VERSION` 改为 `2`。
  3. `needsImport()` 增加「农友表为空」「积分商品表为空」两个判断，需要在 DAO 里加 count 查询。
  4. 更新类注释里「后续模块…」的说明。

## 2. 启动任务

- **文件**：`app/src/main/java/com/heban/app/HeBanApp.java`
- **现状**：`onCreate` 里已经有 `WeatherRefreshWorker.enqueue`（try/catch）和 `mockImporter.importIfNeeded().subscribe(...)`。
- **要加**：
  - 导入完成后执行 `container.communityRepository.refundExpiredRewards()`，后台订阅，忽略错误；
  - `LogisticsWorker.ensureScheduled(this)`，放在 try/catch 中，与 WeatherRefreshWorker 的写法相同；
  - 在兑换成功后（`LocalMallRepository.redeem`）和登录后也调用 `ensureScheduled`，保证有订单时 Worker 在运行。

## 3. 首页 H01 数据接线

**铃铛未读数**
- 现状：`ui/home/HomeViewModel.unreadMessages()` 返回 `Flowable.just(0)`。
- 要改：返回 `c.messageRepository.observeCounts().map(MessageCounts::total)`。
  - 公开构造函数 `HomeViewModel(AppContainer c)` 可以直接拿到 `c.messageRepository`；
  - 测试用的包内构造函数需要加一个参数，并同步更新 `app/src/test/.../ui/home/HomeViewModelTest.java`。

**签到红点**
- 现状：`res/layout/fragment_home.xml` 中的 `checkin_dot` 一直显示。
- 要改：订阅 `c.pointsRepository.observeCheckIn()`，只在 `!checkedToday` 且已登录时显示，绑定 `app:visible`。

## 4. 字体缩放

- **现状**：`SettingsStore.FONT_SCALE`（float，默认 1.0）已定义，没有地方读取。
- **要改**：在 `ui/MainActivity` 重写 `attachBaseContext(Context base)`：
  1. 用 `HeBanApp.container(base).settings.peek(SettingsStore.FONT_SCALE, 1.0f)` 取值。`HeBanApp.onCreate` 已经执行过 `loadBlocking()`，所以 peek 能取到。需要注意 `container(...)` 接收的 Context 类型。
  2. 复制 `base.getResources().getConfiguration()`，设置 `fontScale`，再 `super.attachBaseContext(base.createConfigurationContext(config))`。
- M12 修改字号后调用 `recreate()`。
- 技术准备文档写的是 BaseActivity，本项目为单 Activity，见 04 C。
