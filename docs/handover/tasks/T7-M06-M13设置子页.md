## 数据接口

**账号**：`c.userRepository`
- `currentUser`、`sendCode(phone, SmsScene.RESET_PASSWORD / CHANGE_PHONE)`、`verifyCode`；
- `resetPassword(phone, newPwd)`：会清除登录态；
- `changePhone(newPhone)`、`deleteAccount()`、`isFakeSms()`；
- `FakeSmsService.CODE`：模拟验证码。发送成功后，如果 `isFakeSms()` 为真，显示 `getString(R.string.fake_sms_hint, FakeSmsService.CODE)`，与 A04 相同。

**工具类**：`ui/common/SmsCountdown`（60 秒倒计时）、`ui/common/StepIndicatorView`、`util/PasswordStrength`、`util/PhoneMask`。

**设置项** `SettingsStore`，用 `observe` / `get` / `put` / `peek` 读写：
- M09：`NOTIFY_ENABLED`、`NOTIFY_FARM_TASK`、`NOTIFY_WEATHER`、`NOTIFY_PEST`、`NOTIFY_COMMENT`、`NOTIFY_LIKE`（默认关）、`NOTIFY_FOLLOW`、`NOTIFY_DM`、`NOTIFY_DND_START` / `NOTIFY_DND_END`（一天中的分钟数，默认 22:00–06:30）。
- M10：`PRIVACY_POST_VISIBILITY`、`PRIVACY_REGION_PRECISION`、`PRIVACY_FIND_BY_PHONE`、`PRIVACY_DM`、`PRIVACY_COMMENT`。
- M12：
  - `THEME_MODE`：存 `AppCompatDelegate.MODE_*`，启动时 `HeBanApp` 已经读取并应用；
  - `DYNAMIC_COLOR`：`HeBanApp` 已经按此开关调用 `DynamicColors`；
  - `FONT_SCALE`：已定义，但还没有地方读取，接线见 T10。

**数据导出**：`data/export/DataExporter.export(ctx, c)` → `Single<String>`，返回文件名（T2 新建）。

## 行为要求

### M06 账号与安全

**安全等级卡**
- 规则：已绑定手机 + 已设置密码 = 较高；再完成实名认证 = 高。
- 原型示例为「安全等级：较高」。

**登录方式**
- 手机号：「138****5678 · 用于登录和找回密码」，「换绑」进入 M08。
- 修改密码：「短信验证后设置新密码，无需原密码」，进入 M07。

**设备与认证**
- 登录设备管理：
  - 原型为「Pixel 8（本机）、平板 · 共 2 台」；
  - 实际只能显示本机：`Build.MANUFACTURER + MODEL`「（本机）· 共 1 台」；
  - 点击弹出对话框列出本机。
- 实名认证：「未认证」，副标题「认证后可在集市显示「实名」标识」，点击显示「功能暂未开放」。
- 登录记录：「最近一次：今天 08:12 · 南京」，由 `UserEntity.lastLoginAt` 和地区生成。

**注销账号**
- 对话框文案与原型一致：
  - 标题「确定注销账号？」
  - 后果列表：
    - 删除账号及全部云端数据，无法恢复
    - 动态、问答、集市商品将被删除
    - 积分、等级、徽章全部清零
    - 7 天内重新登录可撤销注销
  - 复选框「我已了解以上后果」，勾选后才能点「注销」。
- 确认后调用 `deleteAccount`，再执行 `NavRoutes.toLogin`。

### M07 修改密码

两步，用 `StepIndicatorView` 显示步骤：「验证身份」→「设置新密码」。

**第 1 步**
- 已绑定手机号，脱敏显示。
- 验证码 +「获取验证码」：倒计时文案「{N}s 后重发」，结束后显示「重新获取」。
- 「下一步」：调用 `verifyCode`。

**第 2 步**
- 新密码：带显示 / 隐藏切换。
- 规则行带对勾图标：
  - 「8–20 位」
  - 「同时包含字母和数字」
  - 「不能与最近使用过的密码相同」
- 确认新密码：不一致和一致时分别给出提示。
- 「确认修改」：调用 `resetPassword`。`SAME_AS_RECENT` 错误显示在对应输入框下方。

**成功态**
- 「密码已修改」及说明（原型文字为「… 本机作物数据不受影响。」）。
- 「重新登录」：执行 `NavRoutes.toLogin`。`resetPassword` 已经清除了登录态。

### M08 换绑手机号

**当前绑定卡**：「当前绑定手机号 +86 138****5678」。

**新手机号**
- 校验提示：
  - 与当前号码相同：「新手机号与当前手机号相同」；
  - 格式错误：「请输入正确的手机号」。
- 验证码：用 `CHANGE_PHONE` 场景发送。

**确认换绑**
- 先弹确认对话框：「换绑到 139****1111？」+「下次登录和找回密码请使用新手机号」，按钮「取消」/「确认换绑」。
- 确认后依次调用 `verifyCode`、`changePhone`。

**成功态**：「换绑成功」+「完成」（返回）。

### M09 消息通知

**总开关「接收通知」**
- 副标题：开启时「已开启 · 也可在系统设置中管理」，关闭时「已关闭，你将错过农事和预警提醒」。
- 关闭前先弹确认对话框。
- 开启时检查 `POST_NOTIFICATIONS` 权限，没有就请求。

**分组开关**：文字全部从 `Notify.dc.html` 复制。
- 农事提醒：农事任务提醒（「按日历时间提醒，每天 07:00 汇总」）、天气预警（「降温、大风、暴雨等，免打扰时段也会提醒」）、病虫害高发提醒（「结合所在地区和在种作物推送」）。
- 互动消息：评论和回答、赞和收藏、新增关注、私信（「包括集市买家咨询」）。
- 总开关关闭时，子开关全部禁用。

**免打扰时段**：「22:00 – 次日 06:30，预警类通知除外」。点击后用两个 MaterialTimePicker 分别选择开始和结束时间，保存到 DND_START / DND_END。

### M12 显示与通用

**主题**：浅色 / 深色 / 跟随系统。保存到 `THEME_MODE`，并调用 `AppCompatDelegate.setDefaultNightMode`。

**动态取色**
- 副标题「跟随壁纸生成配色（Android 12 及以上）」。
- 切换后保存 `DYNAMIC_COLOR`，再调用 `requireActivity().recreate()`。
- minSdk 是 31，所以总是可用。

**字体大小**
- 滑块：小 / 标准 / 大 / 特大，对应 0.875 / 1.0 / 1.125 / 1.25，保存到 `FONT_SCALE`。
- 预览卡「今日农事 3 项 / 给番茄追施钾肥 · 1号大棚」：页内按比例缩放预览文字。
- 全局生效依赖 T10 的 `attachBaseContext`。

**图片缓存**
- 副标题：「128 MB · Glide 磁盘缓存上限 250 MB」，数字为实际大小（原型 JS 中为空时显示 0 B）。
- 「清理」完成后提示「已清理 128 MB 图片缓存」（数字为实际值）。

**离线百科数据**：原型为「36 MB · 已是最新（10月08日）」。建议显示实际条数，如「31 条 · 已是最新」，记入 04。

**语言**：「简体中文」，点击显示「功能暂未开放」。
