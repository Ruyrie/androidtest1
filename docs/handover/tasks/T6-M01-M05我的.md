## 数据接口

- `c.userRepository`：`currentUser`、`updateProfile`、`logout`。
- `c.pointsRepository`：`observeSummary`（balance / growth / level / levelTitle / nextLevelGap）、`observeCheckIn`、`checkIn`。
- `c.communityRepository`：
  - `myStats()`：返回 `[动态, 关注, 粉丝, 获赞]`；
  - `postsBy(0, type)`：取自己的动态或提问，farmerId 传 0 表示当前用户。这一约定要与 T1 的实现保持一致；
  - `favorites()`：收藏的帖子。
- M04 的百科和商品收藏：
  - `c.favoriteRepository.observeAll(FavoriteEntity.TYPE_PEST / TYPE_PRODUCT)`；
  - 详情用 `c.pestRepository.get(id)`、`c.marketRepository.observeProduct(id)`。
- `c.marketRepository.observeMine()`：我的发布。
- `c.cropRepository.observeCropCards(null)`：M02「在种」作物，showCrops 打开时显示。
- `PointsRules`、`AvatarColors`、`BadgeStyles`、`util/PhoneMask`、`NavRoutes.toLogin(nav())`。

## 行为要求

### M01（一级页）

**顶栏**：「我的」+ qr_code_2（点击显示「功能暂未开放」）+ settings（进入 `settingsFragment`）。

**资料卡**
- 头像字（primary 底）、昵称、Lv 徽标（「Lv.4 种植能手」）、「江苏 南京 · 种植 12 年」。
- 「主页 >」：进入 M02。

**统计**：动态 / 关注 / 粉丝 / 获赞。
- 点「关注」进入 `followsFragment`，参数 `FOLLOWS_TAB = following`；
- 点「粉丝」进入 `followsFragment`，参数 `FOLLOWS_TAB = fans`。

**签到卡**
- local_fire_department 图标、「已连续签到 6 天 · 明天满 7 天」、「1,280 积分 · 距 Lv.5 还差 220 成长值」。
- 签到按钮：调用 `checkIn`，再显示 Snackbar，提示得到的积分（文案自拟，记入 04）。已签到时按钮禁用，显示「已签到」。

**菜单行**（与原型一致）

| 行 | 去向 |
|---|---|
| 我的动态 | M02 动态 Tab |
| 我的问答 | M02 问答 Tab |
| 我的收藏 | M04 |
| 我的发布 | 底部弹窗列出 `observeMine`，点击进入 `productFragment`；为空时提供「去发布」，进入 `addProductFragment` |
| 收支记账 | `ledgerFragment` |
| 地块管理 | `plotsFragment` |
| 成就徽章 | `checkInFragment` |
| 积分商城 | `pointsMallFragment` |
| 设置 | `settingsFragment` |
| 帮助与反馈 | 行尾显示「暂未开放」，点击显示「功能暂未开放」 |
| 关于禾伴 | 行尾显示「v1.0.0」，取 `BuildConfig.VERSION_NAME`；进入 `aboutFragment` |

**游客**：资料卡换成「登录 / 注册」卡，点击执行 `NavRoutes.toLogin`；个人统计显示 0 或隐藏。

### M02（我的主页）

**封面**：占位图 + add_photo_alternate。点击后用 PickVisualMedia 选图，复制到 `filesDir`，再调用 `updateProfile` 写入 coverPath。

**头像**：点击更换，流程同封面，写入 avatarPath。

**按钮**：「编辑资料」进入 M03；分享。

**资料区**
- 昵称、Lv 徽标。
- 「未实名 · 去认证」（verified_user）：点击显示「功能暂未开放」。
- 简介。
- 「江苏 南京 · 种植 12 年 · 最近访客 12 人」：没有访客数据，建议隐藏「最近访客」，并记入 04。
- 统计：关注 / 粉丝 / 获赞。
- 徽章行：showBadges 打开时显示，「全部 8」进入 `checkInFragment`。

**Tab：动态 N / 问答 N / 集市 N / 收藏（lock 图标）**
- 动态 Tab 的网格第一格为「发动态」，进入 `publishFragment`。
- 点击动态进入 `postDetailFragment`，问答进入 `questionFragment`，商品进入 `productFragment`。
- 收藏 Tab 显示「收藏仅自己可见，可在 隐私设置 中修改」：
  - 「隐私设置」进入 `privacySettingsFragment`；
  - 「查看我的收藏」进入 M04。

### M03（编辑资料）

**顶栏**：关闭 ×、「编辑资料」、「保存」。

**封面与头像**：「更换封面」；头像带相机角标。

**昵称**
- 计数「N/16」，提示「30 天内可修改 1 次」。
- 锁定期内输入框禁用，并说明还要等多少天。

**个人简介**：计数「N/60」。

**所在地区**
- 项目里没有省 / 市 / 区数据。A06 用的是「输入框 + 定位按钮」（`ui/account/RegisterRegionLocator`：GPS + Geocoder 得到「江苏省 南京市 江宁区」；定位失败提示「定位失败，请手动输入」）。
- 这里沿用这个做法。需要跨包使用时，把 `RegisterRegionLocator` 移到 `ui/common` 并改为 public。

**种植年限**：下拉选择 0–60 年。

**种植身份**：Chip，种植户 / 家庭园艺 / 农技人员。

**擅长作物**
- Chip 带关闭按钮，另有「添加」；最多 5 个。
- 候选项如 大棚管理 / 水肥一体化 / 病虫害防治 / 草莓 …

**开关**：「在主页展示我的作物」「在主页展示成就徽章」。

**保存**
- 调用 `updateProfile`，然后返回并显示 Snackbar（文案自拟，记入 04）。
- `NICKNAME_LOCKED` 错误在昵称框下方显示。

### M04（我的收藏）

**顶栏**：返回、「我的收藏」、搜索（按标题过滤）。

**筛选 Chip**：全部 / 动态 / 问答 / 百科 / 商品。

**收藏项**
- 缩略图标框的配色按类型区分，参照原型。
- 标题 2 行、类型 Chip、meta 行。meta 示例：
  - 「王农艺师 · 356 赞」
  - 「卵菌病害 · 可离线查看」
  - 「¥25 /斤 · 草莓姐姐」
  - 「已解决 · 12 个回答」
- 点击分别进入 postDetail / questionFragment / pestDetailFragment / productFragment。

**空状态**（与原型一致）：bookmark 图标、「还没有收藏」、「看到有用的内容，点 [bookmark 图标] 收藏就能在这里找到」。

### M05（设置）

**分组**
- 账号：
  - 账号与安全，副标题「手机号 138****5678 · 修改密码」（用 `PhoneMask.mask`），进入 `securityFragment`；
  - 隐私设置，进入 `privacySettingsFragment`。
- 通用：消息通知（`notifySettingsFragment`）、显示与通用（`generalSettingsFragment`）、AI 助手设置（`aiSettingsFragment`）。
- 关于：
  - 帮助与反馈：行尾「暂未开放」，点击显示「功能暂未开放」；
  - 关于禾伴：「版本 1.0.0」，进入 `aboutFragment`。

**切换账号**：调用 `userRepository.logout`，再执行 `NavRoutes.toLogin`。

**退出登录**（error 色文字）
- 先弹对话框，文案与原型一致：
  - 标题「退出登录？」
  - 正文「作物和农事数据会保留在本机，重新登录后自动同步。未发送的草稿将被清除。」
  - 按钮「取消」/「退出登录」。
- 确认后：
  1. 对 POST 和 QUESTION 两种草稿分别调用 `communityRepository.deleteDraft`，错误忽略；
  2. 调用 `logout`；
  3. 执行 `NavRoutes.toLogin`。
