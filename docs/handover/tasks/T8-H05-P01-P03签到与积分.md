## 数据接口

**`c.pointsRepository`**（已实现）
- `observeSummary()`：`PointsSummary`，字段有 balance、growth、level、levelTitle、nextLevelGap、monthGain、monthSpend。
- `observeCheckIn()`：`CheckInState`，字段有 checkedToday、streak、todayPoints、week（每天含 date / checked / today / points）。
- `checkIn()`：返回本次得到的积分。
- `observeTxns(filter)`：filter 取 `PointsCalculator.FILTER_ALL` / `FILTER_GAIN` / `FILTER_USE`（值为 `all` / `gain` / `use`），对应 全部 / 获得 / 消耗。
- `observeTodayCount(type)`：今天某类型的次数，用于每日任务状态。

**`PointsRules`**：全部积分常量和等级阈值，包括 `level(growth)`、`levelTitle(level)`。

**`c.mallRepository.observeItems(type)`**：type 为 全部 / 实物 / 装扮（T2 实现）。

**徽章进度的数据源**

| 数据 | 来源 |
|---|---|
| 作物数 | `c.cropRepository.observeCropStats()` |
| 识别次数 | `c.visionRepository.observeHistory()` |
| 我发布的商品 | `c.marketRepository.observeMine()` |
| 连续签到 | `observeCheckIn().streak` |
| 记账天数、采收记录 | 现有表 ledger_entry / farm_record，可以在 DAO 中加只读查询 |
| 回答数 / 被采纳数 | T1 完成后取自 comment 表 |

## 行为要求

### H05 签到与成就

**顶栏**：返回、「签到与成就」、help（进入 `pointsRulesFragment`）。

**主卡**
- 「已连续签到 N 天」；「我的积分 N >」进入 P01。
- 7 天行：
  - 标签「4日 … 今天」；
  - 图标：已签为 check_circle，未签为 event，第 7 天为 redeem；
  - 每天的积分（+10 / +30），已签的日子用完成样式。
- 签到按钮：
  - 今天是连续第 7 天时为「签到领 30 积分（满 7 天奖励）」，否则为「签到领 10 积分」；
  - 签到成功后变为「今日已签到 +30，明天再来」（check_circle），并显示 Snackbar。

**等级卡**：「Lv.4 种植能手 · 距 Lv.5 还差 220 成长值」+ 进度条。

**积分商城入口卡**（redeem）：进入 P03。

**每日任务**

| 任务 | 积分 | 未完成按钮 | 去向 |
|---|---|---|---|
| 发布一条动态 | +5 | 去完成 | `publishFragment` |
| 回答一个问题 | +10 | 去回答 | `qaFragment` |
| 完成今日农事 | +5 | 去完成 | `calendarFragment` |
| 记一笔账 | +2 | 去记账 | `addEntryFragment` |

完成状态来自 `observeTodayCount(PointsRules.TYPE_*)`，次数达到每日上限即为「已完成」。

**成就徽章**：标题「已获得 N/8」，网格中依次为：

| 图标 | 名称 |
|---|---|
| potted_plant | 初次播种 |
| local_fire_department | 连续签到：未满时「连签 6/7 天」，达成后「连签 7 天」（取自原型 JS） |
| volunteer_activism | 热心农友 |
| photo_camera | 识别达人，进度如「识别达人 3/10」 |
| agriculture | 丰收达人 |
| storefront | 集市新星 |
| savings | 记账，进度如「记账 12/30 天」 |
| workspace_premium | 答题王 |

- 已获得的用实心彩色图标，未获得的用线框图标并显示进度文字。
- 阈值：**文档只给出了识别 10 次、记账 30 天、连签 7 天**，其余徽章的达成条件文档没有定义。新建 `ui/home/CheckInBadges.java` 集中计算，自定条件前先**请用户确认**，再记入 04。

**游客**：签到需要登录；页面显示 0 状态。
