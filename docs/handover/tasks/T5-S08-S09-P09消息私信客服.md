## 数据接口

- `c.messageRepository`：
  - `observeCounts`、`observeConversations`、`observeConversation`、`observeMessages`、`observeTyping`；
  - `openConversation(farmerId, productId)`、`openServiceConversation`、`send`、`serviceQuickQuestions`；
  - `markConversationRead`、`markAllRead`、`observeNotifications(type)`、`markNotificationsRead(type)`。
- `c.marketRepository.observeProduct(id)`：S09 顶部的商品卡。
- `c.mallRepository.observeOrders(MallRepository.TAB_SHIP)`：P09 订单卡，取最近一笔运输中的订单。
- `c.userRepository.currentUser()`：我的头像字。
- 模型：`ConversationItem`、`Author`、`MessageCounts`；`NotificationEntity` 的类型为 COMMENT / LIKE / FOLLOW / SYSTEM。

## 已有调用方（参数必须兼容）

- H01 首页铃铛：`navigate(R.id.messagesFragment)`。
- D08 商品详情「私信」：`navigate(R.id.chatFragment, {FARMER_ID: sellerId, PRODUCT_ID: productId})`，需要登录。S09 要支持「用农友 id 打开」：先调用 `openConversation`，再显示会话。

## 行为要求

### S08

**顶栏**
- 返回、「消息」。
- done_all（全部已读）：调用 `markAllRead`，再显示 Snackbar。
- settings：进入 `R.id.notifySettingsFragment`。

**四个入口格**
- 评论回复 / 赞和收藏 / 新增关注 / 系统通知，带图标和未读角标（来自 MessageCounts）。
- 点击后打开该类型的通知列表（底部弹窗或全屏对话框），打开时标记为已读。

**私信区**
- 会话行：头像、昵称、时间、最后一条消息、未读角标，未读时加粗。
- 时间格式：14:32 / 昨天 / 周四 / 10/05。
- 点击进入 S09，参数 `CONVERSATION_ID`；客服会话进入 P09。

**空状态**：新账号默认为空，原型没画，自拟文案并记入 04。

**游客**：显示登录提示状态。

### S09

**参数**：`CONVERSATION_ID`，或 `FARMER_ID`（可加 `PRODUCT_ID`）。

**顶栏**：返回、头像、昵称、「种植能手 · 通常 1 小时内回复」（取农友的 replyNote）、more_vert。

**商品卡**：有 productId 时显示。内容为图片占位、标题、价格、「查看」；点击进入 `productFragment`。

**消息区**
- 日期分隔「今天 14:20」。
- 我的气泡在右，primary 底；对方的在左，surfaceContainerHigh 底。

**输入中提示**：「对方正在输入…」，来自 `observeTyping`。

**输入区**
- 输入栏上方显示防诈骗提示（shield 图标）。
- add_circle：图片消息目前没有仓库方法，点击显示「功能暂未开放」，并记入 04。
- 输入框 + 发送；有内容才能发送。

**已读**：进入页面时，以及页面可见时收到新消息时，调用 `markConversationRead`。

### P09

**顶栏**：返回、头像「禾」（primary 底）+ 认证标识 + 「禾伴客服」+「官方账号 · 自动回复，人工服务暂未开放」。

**订单卡**：显示最近一笔运输中的订单。
- 内容：图标、商品名、状态 ·「预计明天送达」（由 `estimatedAt` 计算）。
- 「查看物流」：进入 `R.id.logisticsFragment`，参数 `ORDER_NO`。
- 没有这类订单时不显示。

**消息区**：第一条消息是开场白。

**输入中提示**：「客服正在输入…」，约 1 秒。

**快捷问题 Chip**：来自 `serviceQuickQuestions`，点击后作为问题发送。

**转人工**：回复「人工服务暂未开放」。

**输入栏**：输入框 + 发送。
