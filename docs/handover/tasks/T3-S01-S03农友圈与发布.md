## 数据接口

- `c.communityRepository`：
  - `feed(tab)`：PagingData，tab 取 `TAB_RECOMMEND` / `TAB_FOLLOWING` / `TAB_QA` / `TAB_LOCAL`；
  - `search(keyword)`、`observePost`、`addView`、`observeComments(postId, SORT_HOT / SORT_NEW)`；
  - `toggleLike`、`toggleCommentLike`、`toggleFavorite`、`toggleFollow`；
  - `comment`、`publish(post, aiAnswer)`、`deletePost`；
  - `getDraft` / `saveDraft` / `deleteDraft`、`topics()`。
- `c.messageRepository.observeCounts()`：信封角标，取 `total()`。
- `c.cropRepository.observeCropCards(null)`：关联我的作物。
- `c.pointsRepository.observeBalance()`：悬赏行的「（余 1,280）」。
- `c.userRepository.currentUser()`：默认位置、我的头像字。
- 模型：`PostCard`、`CommentItem`、`Author`。

## 已有调用方（参数必须兼容）

- C02 作物详情的分享按钮：`navigate(R.id.publishFragment, {CROP_ID})`。S03 收到 `NavArgs.CROP_ID` 时，预选「关联我的作物」。
- D03 识别结果的「发到问答」：`navigate(R.id.publishFragment, {PUBLISH_TYPE: "QUESTION", PUBLISH_TEXT: 识别结论})`。

## 行为要求

### S01（一级页，显示底部导航）

**顶栏**
- 标题「农友圈」，右侧依次为搜索、信封（带未读角标，点击进入 `R.id.messagesFragment`）。
- 搜索：切到页内搜索模式，显示 `search(keyword)` 的结果列表。

**Tab：推荐 / 关注 / 问答 / 同城**
- 「问答」进入 `R.id.qaFragment`（S04 是独立页面，顶部的头部和 Tab 行与 S01 相同）。切换时不能闪烁。

**动态卡片**（与原型完全一致）
- 头像字（AvatarColors），昵称 + 徽标（BadgeStyles），「句容 · 2 小时前」。
- 关注按钮：「关注」/「已关注」，自己的动态不显示。
- 正文 3 行；图片网格按数量规则排列，用占位图。
- 话题标签。
- 操作：
  - 点赞 + 数量：已赞时用 error 色实心图标；
  - 评论 chat_bubble + 数量：进入 S02；
  - 分享：`ACTION_SEND`。

**乐观更新**
- 点赞和关注先改界面，再调用仓库；失败时回滚并显示 Snackbar。
- 每个按钮用 `throttleFirst(800ms)` 防连点。

**其他**
- FAB「发布」（edit 图标）：进入 S03，需要登录。
- 空状态：
  - 关注 Tab 没有关注任何人：「还没有关注的农友」；
  - 同城 Tab 没有地区（游客或资料没有地区）：说明原因。
- 深色模式与 `S01_CommunityDark.png` 一致。

### S02（参数 `NavArgs.POST_ID`）

**顶栏**：返回、作者（头像、昵称、「种植能手 · 句容」）、关注按钮、more_vert。
- 别人的动态：more_vert 菜单为「举报」。原型没画结果，建议 Snackbar「已收到你的举报」，并记入 04。
- 自己的动态：more_vert 菜单为「删除」，先确认，再 `deletePost`，然后返回。

**正文区**
- 全文、图片（Picasso fit + centerCrop）、话题。
- 「句容市白兔镇 · 10月10日 13:20」。
- 操作行：点赞、评论、收藏（bookmark，已收藏）、分享。

**评论区**
- 标题「评论 N」，排序下拉「最热 / 最新」。
- 评论项：头像 32dp、昵称、内容、「1 小时前 · 回复」、点赞数。
- 作者回复块：「草莓姐姐 作者 ：…」，带「作者」标识。

**底部输入栏**
- 我的头像字 + 输入框 + 发送；有内容才能发送，需要登录。
- 新评论显示在列表顶部，作者为「<我的昵称>（我）· 刚刚」（原型示例为「老李种菜（我）」）。

**浏览数**：页面打开时调用一次 `addView`。

### S03（可选参数 `PUBLISH_TYPE`、`PUBLISH_TEXT`、`CROP_ID`）

**顶栏**：关闭 ×、分段按钮「动态 / 提问」、文字按钮「发布」。

**提问模式**
- 多一个「问题标题」输入框（原型示例「番茄叶片卷曲发黄，是缺什么肥？」）。
- 「悬赏积分」行：显示「（余 1,280）」，原型选中值为「20 积分」。
  - 文档只规定 10–100。建议选项为 不悬赏 / 10 / 20 / 50 / 100，超过余额的选项禁用，并记入 04。
- 「让 AI 先给参考答案」开关。

**正文框**
- 两种模式的占位文字不同：动态模式为「分享你的种植经验、收获或者遇到的趣事…」，提问模式见原型。
- 右下角计数「N/1000」。

**图片行**
- 用 PickMultipleVisualMedia 选图，最多 9 张。
- 复制到 `filesDir/posts/`，以 `file://` URI 保存。

**设置行**
- 话题：从 `topics()` 选择。
- 关联我的作物：作物选择器。
- 所在位置：默认取资料中的地区，如「南京 · 江宁区」。
- 谁可以看：所有人 / 我关注的人 / 仅自己。

**底部工具行**：图片、相机、话题、@，按原型。

**草稿**
- 打开时读取草稿，离开时保存草稿，两种模式各一份；发布成功后删除。

**发布**
- 先校验，然后调用 `publish`，显示 Snackbar。
- 动态：进入 S02；提问：进入 S05（`R.id.questionFragment`），参数都是 `POST_ID`。导航时把 publishFragment 弹出返回栈（popUpTo publishFragment inclusive）。
- 打开页面和发布时都需要登录。
