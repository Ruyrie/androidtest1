## 数据接口

- `c.communityRepository`：
  - `questions(filter)`，filter 取 `Q_ALL` / `Q_OPEN` / `Q_MY_CROPS` / `Q_MINE`；
  - `observePost`、`observeComments`、`answer`、`accept`、`toggleCommentLike`、`toggleFollow`；
  - `observeFarmer`、`postsBy(farmerId, type)`、`answersBy(farmerId)`、`following()`、`fans()`、`addView`。
- `c.messageRepository.openConversation(farmerId, null)`：S06 的「私信」，拿到会话 id 后进入 `R.id.chatFragment`，参数 `NavArgs.CONVERSATION_ID`。
- `c.userRepository.currentUser()`。
- **S06「集市」Tab**：`MarketRepository` 目前没有按卖家查询的方法。在 `ProductDao` 增加按 `seller_id` 查询，并在 `MarketRepository` / `LocalMarketRepository` 增加 `Flowable<List<ProductEntity>> productsBySeller(long sellerId)`。改接口后，记得同步更新测试里的假仓库。
- 模型：`PostCard`、`CommentItem`、`FarmerCard`、`FollowRelation`。

## 行为要求

### S04

**头部**：与 S01 相同（「农友圈」+ 搜索 + 信封），Tab 行中「问答」为选中状态。点「推荐 / 关注 / 同城」回到 `R.id.communityFragment`，并切到对应的 Tab。

**筛选 Chip**：全部 / 待解决 / 与我作物相关 / 我的提问。

**问题卡片**
- 内容：标题、预览 2 行、可选的图片占位。
- 状态 Chip：
  - 待解决：pending 图标，surfaceContainerHighest 底；
  - 已解决：check_circle 图标，primaryContainer 底。
- 悬赏 Chip：paid 图标，warning 色。
- meta 行：「菜园小周 · 昨天 · 12 个回答」。
- 点击进入 S05。

**FAB「提问」**（contact_support）：进入 `R.id.publishFragment`，参数 `PUBLISH_TYPE = "QUESTION"`，需要登录。

**空状态**：每个筛选条件分别有空状态，例如「我的提问」为空时提示去提问。

### S05（参数 `NavArgs.POST_ID`）

**顶栏**：返回、「问题详情」、分享、more_vert。

**问题区**
- 状态 Chip、悬赏 Chip、话题、标题、正文、图片。
- meta 行：「老李种菜（我）· 3 小时前 · 浏览 326 · 9 人关注」。

**AI 参考答案卡**：有 ai_answer 时显示。
- 图标 auto_awesome，标签「仅供参考」。
- 可折叠：「展开全部 / 收起」。

**农友回答区**
- 标题「农友回答 N」。
- 提示文字：
  - 提问者看到「你是提问者，可采纳一个回答」；
  - 采纳后变为「已采纳，20 积分已发放给回答者」。

**回答项**
- 头像、昵称、徽标、「已采纳」标签、正文。
- 赞同 thumb_up + 数量（`toggleCommentLike`）、回复、时间。
- 「采纳」按钮：只在问题为 OPEN 时对提问者显示。点击先确认，再调用 `accept`。采纳后该回答移到最上面，其他「采纳」按钮隐藏。

**底部栏**
- 提问者：
  - 「补充描述」：在对话框里输入，追加到正文后（`PostEntity` 更新）。需要的话，在仓库里加一个方法。
  - 「邀请专家回答」：原型没画结果，建议 Snackbar 提示已邀请，并记入 04。
- 非提问者：回答输入栏，需要登录，调用 `answer()`。

### S06（参数 `NavArgs.FARMER_ID`）

**头部**：封面占位、返回、more_vert；头像字（AvatarColors）。

**按钮**
- 关注按钮按 `FollowRelation` 显示 4 种状态：关注（add）/ 已关注（check）/ 回关 / 互相关注。
- 私信（chat_bubble）：需要登录。

**资料区**
- 昵称 + 认证标识；Lv 徽标 + 种植能手；「回答被采纳 68 次」；简介。
- 「江苏 句容 · 种植 8 年 · 加入禾伴 326 天」。
- 统计：关注 / 粉丝 / 获赞。关注后粉丝数 +1，原型 JS 为 `1203 + (followed ? 1 : 0)`。
- 「在种」作物 Chip：来自 cropsJson，带图标。

**Tab：动态 N / 问答 N / 集市 N**
- 动态：图片网格，显示占位图 + 点赞数，点击进入 S02。
- 问答：「回答了：…」/「回答被采纳：…」 + 时间 · 赞同数，点击进入 S05。
- 集市：商品图、标题、价格，点击进入 `R.id.productFragment`，参数 `PRODUCT_ID`。

### S07（可选参数 `NavArgs.FOLLOWS_TAB` = `fans` / `following`）

S07 是当前用户自己的列表。

**顶栏**：返回 + 我的昵称 + person_add。原型没有画后续页面，点击 person_add 显示「功能暂未开放」，并记入 04。

**Tab**：粉丝 N / 关注 N。下方有搜索框，按昵称过滤。粉丝 Tab 有分组标题「最近关注你的农友」。

**列表行**
- 头像、昵称、徽标、副标题（如「句容 · 种草莓 8 年」）、关系按钮。
- 关系按钮：
  - 粉丝 Tab：「回关」/「互相关注」（sync_alt 图标）；
  - 关注 Tab：「已关注」/「互相关注」。
- 点击调用 `toggleFollow`，乐观更新，失败时回滚。

**空状态**：新账号默认为空。
- 「还没有粉丝」/「还没有关注的农友」；
- 按钮「去农友圈看看」，进入 `communityFragment`。

## 测试要点

- 提问者 / 非提问者看到的按钮不同；

- 4 种关注关系的切换；
- 关注后粉丝数 +1；
- 搜索过滤。
