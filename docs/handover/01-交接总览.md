## 1. 项目是什么

「禾伴」是面向种植户和家庭园艺用户的 Android App（课程：Android 企业框架开发）。功能模块：账号、首页（天气 / 农事日历 / 签到）、作物与地块、发现（拍照识别 / 病虫害百科 / AI 农技助手 / 农产品集市 / 收支记账）、农友圈（动态 / 问答 / 私信）、我的与设置、积分商城。

**三份设计依据**（开发必须严格按它们实现，冲突时以「04 差异与决策记录」为准）：

## 3. 环境与构建

| 项 | 值 |
|---|---|
| 语言 / 框架 | Java 11（不用 Kotlin、不用 Compose），MVVM + DataBinding + RxJava 3 |
| AGP / Gradle | AGP 9.0.1，Gradle 9.2.1（wrapper） |
| SDK | compileSdk 36（`release(36){ minorApiLevel = 1 }`），minSdk 31，targetSdk 36 |
| JDK | 开发时使用 OpenJDK 21 |
| 包名 / applicationId | `com.heban.app` |
| 版本库 | `gradle/libs.versions.toml`。注意：Glide 固定 5.0.7、OkHttp 固定 5.4.0（更新版本要求 compileSdk 37） |
| Flavor | `mock`（默认开发用：账号数据存本机 Room，短信可走模拟）/ `remote`（账号走后端接口，后端地址 `https://api.heban.example/` 仍是占位） |

**构建与测试命令**（在仓库根目录）：

```bash
export ANDROID_HOME=/path/to/android-sdk     # 或在 local.properties 里写 sdk.dir
./gradlew :app:assembleMockDebug :app:assembleRemoteDebug
./gradlew :app:testMockDebugUnitTest :app:testRemoteDebugUnitTest
```

> 若 `gradlew` 没有执行权限，用 `bash gradlew …` 或 `chmod +x gradlew`。

**`local.properties`（不入库，已在 `.gitignore`）**，全部注入 `BuildConfig`（见 `app/build.gradle` 的 `configKeys`）：

| 键 | 默认值 | 用途 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 空 | AI 问答 / 识图主模型（DeepSeek） |
| `DEEPSEEK_CHAT_MODEL` | `deepseek-v4-flash` | 问答模型名 |
| `DEEPSEEK_VISION_MODEL` | `deepseek-v4-flash-vision-exp` | 识图主模型名 |
| `DASHSCOPE_API_KEY` | 空 | 识图备用模型（通义千问 VL） |
| `QWEN_VL_MODEL` | `qwen-vl-plus` | 备用识图模型名 |
| `QWEATHER_API_HOST` / `QWEATHER_API_KEY` | 空 | 和风天气（每个账号独立的 API Host + `X-QW-Api-Key`） |
| `SMS_PROVIDER` | `fake` | `fake`（验证码固定 `123456`，界面会提示「模拟短信：验证码 123456」）或 `aliyun` |
| `ALIYUN_AK_ID` / `ALIYUN_AK_SECRET` / `ALIYUN_SMS_SIGN_NAME` | 空 | 阿里云号码认证 · 短信认证（RAM 子账号） |
| `ALIYUN_SMS_TPL_LOGIN` / `_RESET` / `_CHANGE_PHONE` | `100001` / `100003` / 空 | 短信模板 |

- 没有配置 Key 的功能**只显示错误提示，不显示示例数据**（用户决定）：天气卡片显示「未配置天气服务，请在 local.properties 中填写和风天气的 API Host 和 Key」，AI 提示到「AI 助手设置 → 模型服务」配置。
- 用户也可以在 App 内「AI 助手设置 → 模型服务」填写自己的 Key 或任意 OpenAI 兼容服务（Key 经 Android Keystore 加密后存 DataStore）。

## 5. 如何验证页面与原型一致

- 原型 PNG 是 824×1830（412×915 dp 的 2 倍图）。
- 本项目在开发中用 **Robolectric 本地截图**对比原型（不提交到仓库）：
  - 把 `docs/tools/robolectric-local.gradle` 放到 `~/.gradle/init.d/`（它给单元测试加上 Robolectric 4.17 和 androidx.test:core 1.7.0，并加上 JDK 21 需要的 `--add-opens`）。
  - 把 `docs/tools/PageScreenshotTest.java.txt` 复制为 `app/src/test/java/com/heban/app/tmpcheck/PageScreenshotTest.java`。**`tmpcheck/` 目录只用于本地检查，不要提交**：在本地 `.git/info/exclude` 里加一行 `app/src/test/java/com/heban/app/tmpcheck/`（该文件不入库，每个克隆都要自己加）。已提交的单元测试必须是纯 JVM 测试，不依赖 Robolectric。
  - 截图尺寸 1236×2745（412×915dp @3x），深色模式用限定符 `w412dp-h915dp-night-xxhdpi`。
  - 运行：`./gradlew :app:testMockDebugUnitTest --tests 'com.heban.app.tmpcheck.*'`，把输出 PNG 与原型逐一对比（位置、文字、间距、颜色、深色模式）。
  - 需要数据时，在测试里替换 `HeBanApp.container(ctx).xxxRepository` 为假实现（这些字段故意不是 `final`），或用真实仓库写入 Room 后启动 `MainActivity`。登录：`container.settings.saveSession(userId, null).blockingAwait()`。
- 网络受限环境可用 `docs/tools/central-mirror.gradle`（把 Maven Central 指向 Google 镜像），按需放到 `~/.gradle/init.d/`。
