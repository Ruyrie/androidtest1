## 2. 分层与写法（MVVM）

- **Fragment**（视图）继承 `ui/common/BaseFragment`，布局 `res/layout/fragment_<snake_name>.xml`，根节点 `<layout>`，变量 `vm`；`binding.setLifecycleOwner(getViewLifecycleOwner())`。
- **ViewModel** 继承 `BaseViewModel`，构造函数签名必须是 `(AppContainer c)`；在 Fragment 里用 `viewModel(XxxViewModel.class)` 获取。导航子图内共享 ViewModel：
  `new ViewModelProvider(nav().getBackStackEntry(R.id.xxx_graph), HeBanApp.factory(requireContext())).get(X.class)`。
- **Repository** 方法内部已切到 io 线程；ViewModel 用 `.observeOn(AndroidSchedulers.mainThread())` 并 `add(disposable)`；错误统一 `AppError.from(e).message`（BusinessException 的 message 就是给用户看的中文）。
- 一次性消息：ViewModel 的 `SingleLiveEvent`（如 `toast`），Fragment 里 `Snackbars.show(view, text)`。一次性导航同理。
- 输入框双向绑定 `@={vm.xxx}`（`MutableLiveData<String>`），点击 `android:onClick="@{() -> vm.xxx()}"`。
- 顶栏 `MaterialToolbar` + `@style/Widget.HeBan.Toolbar`，返回用 `@drawable/ic_arrow_back`（原型画 × 的用 `ic_close`）→ `nav().navigateUp()`。Activity 已处理状态栏内边距。
- **导航**：按目的地 id 导航，不新增 action；参数用 `Bundle`，键用 `ui/common/NavArgs` 里的常量。登录后进入首页 `NavRoutes.enterHome(nav())`，回登录页 `NavRoutes.toLogin(nav())`。
- **游客只能浏览**：任何写操作（添加作物 / 记录 / 任务 / 地块、记账、AI、点赞、评论、发布、签到、兑换 …）前在 Fragment 里调用 `if (!LoginRequired.check(this)) return;`。仓库层未登录写操作抛 `BusinessException("NOT_LOGGED_IN", "请先登录")`。
- **数据按账号隔离**：所有个人数据表有 `user_id`，仓库通过 `CurrentUser.observeUserId()` 切换查询（未登录为 0，返回空）。
- **新账号没有示例数据**：个人数据（地块、作物、农事、记账、积分、关注、动态、订单、地址、私信、通知）一律从空开始，每个列表都要有空状态（图标 + 一句说明 + 可选按钮）。共享的模拟内容（病虫害百科、集市商品、农友、动态、问答、积分商品）对所有账号都导入。
- **缺 Key 只提示错误**，不展示假数据。

## 4. 数据库（Room，`AppDatabase` version 4）

实体（`data/local/entity/`）：`UserEntity`、`AppealEntity`、`PlotEntity`、`CropEntity`、`FarmRecordEntity`、`FarmTaskEntity`、`LedgerEntryEntity`、`WeatherCacheEntity`、`ChatSessionEntity`、`ChatMessageEntity`、`ScanRecordEntity`、`PestEntity`、`ProductEntity`、`FavoriteEntity`、`CheckinEntity`、`PointsTxnEntity`、`FarmerEntity`、`PostEntity`、`CommentEntity`、`FollowEntity`、`FanEntity`、`LikeEntity`、`ConversationEntity`、`DirectMessageEntity`、`NotificationEntity`、`DraftEntity`、`MallItemEntity`、`MallOrderEntity`、`AddressEntity`。

- 金额统一存「分」（`*_cent`）；时间统一存毫秒。
- 开发阶段使用破坏性迁移；正式发布前固定版本并编写 Migration（技术准备文档 7.1）。
- 多表写操作用 `db.runInTransaction`（例如农事记录同步记账、置顶扣积分、兑换扣积分）。

## 11. 开发中踩过的坑

- `gradlew` 在某些环境没有执行权限 → `bash gradlew`。
- Glide 5.0.9 / OkHttp 5.5.0 需要 compileSdk 37 → 已固定为 5.0.7 / 5.4.0，不要随意升级。
- Robolectric 在 JDK 21 上需要 `--add-opens java.base/jdk.internal.access` 和 `java.io`（已写在 `docs/tools/robolectric-local.gradle`）。
- Robolectric 不安装 PicassoProvider；本地截图测试里如用 Picasso 需自行 `Picasso.setSingletonInstance`（App 启动时已在 `HeBanApp` 配置）。
- Robolectric 软件渲染不画卡片阴影 / 圆角裁切，截图里卡片看起来是方角无阴影，真机正常。
- 引用 Material 主题属性要写 `com.google.android.material.R.attr.*`（见第 6 节）。
- `WorkManager.getInstance` 在未初始化时会抛 `IllegalStateException`（如测试环境），调用处已 try/catch。
